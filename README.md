# 💻 Інформатика — сайт для дня відкритих дверей

Сайт-презентація кабінету інформатики **Буського ЗЗСО — Гімназії ім. Є. Петрушевича при ЛНУ ім. І. Франка**.

Напрями: **Python · Scratch · 3D-графіка · 3D-друк** + галерея робіт учнів, які можна запускати прямо в браузері.

---

## 🚀 Як відкрити сайт

**Найпростіше:** двічі клацніть на файлі `index.html` — сайт відкриється у браузері.

**Рекомендовано (через локальний сервер):** відкрийте термінал у папці сайту та виконайте:

```bash
python -m http.server 8000
```

Потім відкрийте у браузері адресу `http://localhost:8000`.

> ⚠️ **Запуск Python-програм на сайті потребує інтернету** — середовище Python
> (Pyodide, ~10 МБ) завантажується з інтернету при першому запуску. Все інше
> (3D-сцена, галерея, фото) працює і без інтернету.

---

## ➕ Як додати роботу учня

Усі роботи описані в **одному файлі**: `js/works-data.js`. Відкрийте його у Блокноті
(або будь-якому редакторі), скопіюйте готовий блок і змініть дані.

### 🐍 Python-програма

```js
{
  type: "python",
  title: "Назва програми",
  author: "Ім'я, 8 клас",
  description: "Один-два речення про те, що робить програма.",
  code: `
print("Вставте код програми сюди!")
`,
},
```

> Код вставляється **між символами `` ` `` (бектиками)**. Відвідувачі зможуть
> запустити його кнопкою «▶ Запустити» та навіть змінити!
> Працюють `print()`, `input()`, цикли, списки, `random` та інші стандартні модулі.

### 📷 Фото (наприклад, 3D-модель або виріб з принтера)

1. Покладіть файл фото у папку `works/images/` (наприклад, `works/images/robot.jpg`)
2. Додайте блок:

```js
{
  type: "image",
  title: "Назва роботи",
  author: "Ім'я, 9 клас",
  description: "Опис роботи.",
  file: "works/images/robot.jpg",
},
```

### 🎬 Відео

1. Покладіть відео у папку `works/videos/` (формат `.mp4` — найнадійніший)
2. Додайте блок:

```js
{
  type: "video",
  title: "3D-принтер у роботі",
  author: "Гурток STEM",
  description: "Таймлапс друку моделі.",
  file: "works/videos/print.mp4",
},
```

### 🐱 Scratch-проєкт

1. Проєкт має бути **опублікований** на [scratch.mit.edu](https://scratch.mit.edu)
2. Скопіюйте цифри з адреси проєкту: `https://scratch.mit.edu/projects/`**`123456789`**`/`
3. Додайте блок:

```js
{
  type: "scratch",
  title: "Моя гра",
  author: "Ім'я, 6 клас",
  description: "Опис гри.",
  scratchId: "123456789",
},
```

> Scratch-проєкти відтворюються через [TurboWarp](https://turbowarp.org) — потрібен інтернет.

Відкрийте файл `js/config.js` — там назва школи, адреса, телефон і email.

## 🌐 Як опублікувати сайт в інтернеті (безкоштовно)

**Варіант 1 — GitHub Pages:**
1. Створіть репозиторій на [github.com](https://github.com), завантажте всі файли
2. Settings → Pages → Source: `main` branch → Save
3. Сайт буде доступний за адресою `https://ваш-логін.github.io/назва-репозиторію/`

**Варіант 2 — Netlify Drop:** просто перетягніть папку сайту на [app.netlify.com/drop](https://app.netlify.com/drop).
